# ADR-0004: VOICEVOX を APK に同梱する

- ステータス: 採択
- 日付: 2026-11
- 範囲: フォーク Novelty-local のみ

## 背景

端末の音声合成（Google の TTS など）は抑揚が乏しく、小説の朗読には物足りない。
VOICEVOX は端末の中で動く日本語の音声合成で、コア・ONNX Runtime・声のモデルの利用規約は、
いずれもクレジットを表記すればアプリに組み込んで再配布できるとしている。

## 決定

1. `voicevox_core` 0.17.1（Java API）・VOICEVOX ONNX Runtime 1.23.2（android-arm64）・Open JTalk の辞書・
   声のモデル（四国めたん・ずんだもん・九州そら・東北きりたん）を、CI で公式の配布物から取得して APK に同梱する。
   リポジトリには入れない。
2. アプリの中でダウンロードする方式は採らない（利用者の判断）。
3. クレジットを `THIRD_PARTY_NOTICES.md`・アプリのライセンス画面・README に表示する。

## 代替案

- **初回起動時にダウンロードする**：APK は小さくなる。ただし、ダウンロードの失敗・再開・保存場所の管理が要り、
  オフラインでは初回に使えない → 利用者の判断で却下
- **端末の音声合成だけにする**：大きさは元のまま。ただし、朗読の質が足りない → 却下

## 結果

- APK が約 450MB になった（声のモデルが約 300MB）。
- スマホでは Actions の成果物（zip）を展開できないため、APK をリリース `apk-latest` に直接上げる。
- 長時間の読み上げでのネイティブのメモリ不足に、別途の対策が要った（`VoicevoxBridge.kt` の先頭のコメントを参照）。
